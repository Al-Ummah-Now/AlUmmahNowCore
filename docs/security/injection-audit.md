# Injection Security Audit — AlUmmahNowCore

Audit scope: all Rust workspace crates (`aun-common`, `aun-api`, `aun-auth`, `aun-downloads`, `aun-i18n`, `aun-media`, `aun-player`, `aun-search`, `aun-sync`, `aun-telemetry`, `aun-updates`, `aun-upload`, `aun-ffi`).

## Findings

| Component | Input | Risk | Status | Regression Test |
|---|---|---|---|---|
| `aun-api` (`ApiClient::send_once`) | `RequestSpec.path` and `RequestSpec.headers` (direct Rust / `OfflineQueue` replay) | Authority/scheme injection (`@evil.example`, `//evil.example`) or reserved header override (`Authorization`, `Host`, `Cookie`) could send bearer tokens to a foreign host | Fixed (`resolve_request_url` origin check + `is_reserved_header` guard) | `crates/aun-api/tests/client.rs::refuses_cross_origin_redirect_authority_injection_and_reserved_headers` |
| `aun-api` (`http_client` TLS/redirect policy) | HTTP 3xx `Location` header | Cross-origin HTTPS redirects on API/OAuth/TUS/telemetry requests could leak custom headers (`channelId`, `Idempotency-Key`, `X-AUN-Client`, `AuthorizationSignature`) or forward bodies | Fixed (same-origin + `is_secure` redirect policy) | `crates/aun-api/tests/client.rs::refuses_cross_origin_redirect_authority_injection_and_reserved_headers` |
| `aun-ffi` (`build_request` / `finish_request`) | `ApiCall.headers` | Reserved client-managed headers (`Authorization`, `Cookie`, `Host`, `Content-Length`, `Transfer-Encoding`, `X-AUN-Client`) were only rejected in `PathCall`, not `ApiCall` | Fixed (enforced in `finish_request` for both `ApiCall` and `PathCall`) | `crates/aun-ffi/src/api.rs::tests::rejects_unknown_operation_and_bad_json` |
| `aun-api` (`encode_path` / OpenAPI generated paths) | Path parameters (`video_id`, `channel_id`, `locale`, etc.) | Path traversal / segment injection | OK (`encode_path` percent-encodes non-unreserved bytes and rejects empty/dot-only segments across all generated and hand-written routes) | `crates/aun-api/src/client.rs::tests::encodes_path_segments` |
| `aun-auth` (`OAuthConfig::discover`) | `/.well-known/oauth-authorization-server` JSON | RFC 8414 issuer mismatch or foreign `token_endpoint`/`revocation_endpoint` steering tokens to an attacker host | Fixed (exact issuer match + same-origin check on all discovered endpoints) | `crates/aun-auth/tests/auth.rs::discovery_rejects_mismatched_issuer_and_foreign_endpoints` |
| `aun-auth` (`OAuthClient::exchange_code`) | OAuth redirect callback URL | `error` handled before `state` verification (forged cancel/CSRF), duplicate `state`/`code` parameter pollution, silent skip if `pending.redirect_uri` unparseable | Fixed (strict `pending.redirect_uri` parse, duplicate param rejection, `state` verified before `error`) | `crates/aun-auth/tests/auth.rs::exchange_code_checks_state_before_error_and_rejects_duplicate_params` |
| `aun-common` (`short_link_origin_for`) | Site host / origin string | Unvalidated characters (`\r\n`, spaces, empty labels) in `*.alummahnow.link` host interpolated into `https://{host}` | Fixed (RFC-compliant DNS hostname validation in `extract_host`) | `crates/aun-common/src/short_links.rs::tests::resolves_origins_across_environments` |
| `aun-upload` (`UploadEngine::reauthorise`) | Server-supplied `tusUploadId` | Raw string interpolation into `{tus_endpoint}/{tusUploadId}` allowed path traversal or query injection on authenticated proxy URL | Fixed (`aun_api::client::encode_path` validation/encoding) | `crates/aun-upload/tests/engine.rs::reauthorise_rejects_traversal_in_tus_upload_id` |
| `aun-upload` (`TusClient::create` & `headers`) | `Upload-Metadata` keys and `TusTarget::Direct` headers | Metadata key injection (spaces/commas/CR-LF), silent drop on invalid header, reserved header override (`Host`, `Cookie`, `Authorization`) on direct uploads | Fixed (strict TUS metadata key validation, error on invalid header, reserved header blocklist) | `crates/aun-upload/src/tus.rs::tests::create_rejects_injected_metadata_keys_and_disallowed_direct_headers` |
| `aun-upload` (`ManifestStore`, `FolderWatcher`) | Upload IDs, watched files | Path traversal in manifest IDs; symlink/hard-link escape in watch folder | OK (alphanumeric/`-`/`_` ID validation; `symlink_metadata`, `nlink == 1`, and canonical root containment check) | `crates/aun-upload/src/store.rs::tests::rejects_path_like_ids`, `crates/aun-upload/src/watch.rs::tests::reports_new_stable_video_once` |
| `aun-media` (`to_webvtt`) | `Transcript.language`, `TranscriptWord.text` | Newline injection in `Language:` header or word-timed cues could inject WebVTT `STYLE` blocks or synthetic cues | Fixed (sanitise `language` to ASCII tag chars; flatten whitespace in `word_timed_line` before `escape_vtt`) | `crates/aun-media/src/transcribe/subtitles.rs::tests::webvtt_blocks_header_and_word_cue_injection` |
| `aun-media` (`ModelManager`, `HttpModelFetcher`) | Model descriptor `file_name` and download URL | Path traversal in custom catalog `file_name`; cleartext URL / insecure HTTP redirect downgrade in `HttpModelFetcher` | Fixed (`is_safe_model_filename` check; `ensure_secure_url` + secure redirect policy on `HttpModelFetcher`) | `crates/aun-media/src/transcribe/models.rs::tests::catalogue_is_well_formed` |
| `aun-media` (`UploadHandoffBuilder`, `renditions_files`) | Transcript locale, rung directory names | Path traversal writing caption files or reading HLS renditions | OK (strict ASCII alphanumeric/`-` validation on locale and rung names) | `crates/aun-media/src/handoff.rs::tests::rejects_a_language_that_could_escape_the_directory` |
| `aun-updates` (`hosts::allowed_download_url`, `verify::check_manifest`) | Repo name, download/redirect URL, manifest artifact URL | Path traversal (`..`, `%2e`, `%2f`) in repo name or artifact URL bypassing prefix match | Fixed (strict repo name check, percent-encoded traversal rejection, parsed URL + segment check on artifacts) | `crates/aun-updates/src/hosts.rs::tests::hops`, `crates/aun-updates/tests/updates.rs::rejects_traversal_in_artifact_url` |
| `aun-downloads` (`DownloadStore`) | `local_path`, `thumbnail_path` | Path traversal, absolute paths, URI schemes, NUL bytes | OK (`validate_and_normalize_relative_path` & `normalize_disk_path_safe` reject all traversal/URIs/NULs) | `crates/aun-downloads/tests/downloads.rs` |
| `aun-i18n` (`DiskCache`) | Locale code | Path traversal in cache file path | OK (ASCII alphanumeric/`-` check in `bundle_path`) | `crates/aun-i18n/src/cache.rs::tests::roundtrip_and_overwrite` |
| `aun-telemetry` (`scrub`) | Event properties, crash messages, breadcrumbs | PII/token/log leakage | OK (scrubbed by `aun-telemetry::scrub`; JSON-serialised on wire) | `crates/aun-telemetry/src/scrub.rs::tests::delimiter_and_whitespace_bypasses_are_caught` |
| Local SQL / Process launches / WebViews | N/A | SQL injection, command injection, WebView XSS | OK (none present in `AlUmmahNowCore`: no SQLite/SQL crates, no `std::process::Command` in runtime crates, no WebViews) | N/A |
